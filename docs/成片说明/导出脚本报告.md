# 成片导出脚本报告（2026-10-29）

## 怎么用

都在项目根目录执行，页面用 film-main 的 5194。正式出片按顺序跑这五条：

```
python3 scripts/final/export_segment.py 'http://localhost:5194/frames.html?frame=opening&theme=light' /tmp/final/opening.mkv 0 30 --scale 2
python3 scripts/final/export_segment.py 'http://localhost:5194/frames.html?frame=film&theme=light' /tmp/final/film.mkv 30 103 --scale 2
python3 scripts/final/export_segment.py 'http://localhost:5194/frames.html?frame=ending&theme=light' /tmp/final/ending.mkv 103 120 --scale 2
python3 scripts/final/assemble.py --seg /tmp/final/opening.mkv:0:30 --seg /tmp/final/film.mkv:30:103 --seg /tmp/final/ending.mkv:103:120 --audio 音频/全片音效.wav --out 成片/本体能力演示
python3 scripts/final/check_final.py 成片/本体能力演示-4K60.mp4 --seg 'http://localhost:5194/frames.html?frame=opening&theme=light:0:30' --seg 'http://localhost:5194/frames.html?frame=film&theme=light:30:103' --seg 'http://localhost:5194/frames.html?frame=ending&theme=light:103:120'
```

- `export_segment.py URL OUT.mkv START END [--scale 2] [--from-frame N]`：第 n 帧是 t = START + n/60，共 round((END−START)×60) 帧；输出无损 H.264（qp 0、yuv444p）mkv，60 帧。地址自动补 play=0，开录前确认画面静止。中途断了用 `--from-frame N` 续导成另一个文件，把它当第二段传给 assemble（时间从 START + N/60 起算）。
- `assemble.py --seg FILE:START:END … --audio WAV --out 前缀 [--pad-audio]`：查段、无损拼接、拼接点逐像素比对、出 4K 和 1080p、ffprobe 核对、两张拼版、写 成片记录.json、删中间文件。mkv 和 mp4 都能接。
- `check_final.py 视频 --seg 'URL:START:END' … [--audio-only]`：每 2 秒抽一帧和页面比（门槛 2.0），量响度和真峰值（≤ −1 dBTP），查首尾静音。

## 演练（1080p 素材，输出在 /tmp/final-rehearsal/）

两段样片 0–30、30–120，音轨 0–64 秒加 `--pad-audio`。

| 步骤 | 结果 | 耗时 |
| --- | --- | --- |
| 段检查 | 1800 + 5400 帧，30.000 + 90.000 秒，首尾相接 | 0.07 秒 |
| 拼接 | -c copy | 0.10 秒 |
| 拼接点 | 30 秒处前后四帧与原段逐像素相同；跨缝相邻两帧平均通道差 0.132（只报告） | 7.84 秒 |
| 4K 成品 | 120.000 秒、7,200 帧、3840×2160、60 帧、音轨 120.000 秒 | 185.9 秒 |
| 1080p 成品 | 同上，1920×1080 | 60.0 秒 |
| ffprobe 核对 | 两条都过 | 0.12 秒 |
| 拼版 | 每 0.5 秒 1.97 MB、每 3 秒 0.33 MB（都在 20 MB 内） | 8.83 秒 |
| 记录与清理 | 成片记录.json 已写，中间文件已删 | 约 0.1 秒 |
| 音轨检查 | −21.8 LUFS，真峰值 −1.4 dBTP（门槛 −1）；开头 0.3 秒 −84.3 dB、结尾 0.5 秒 −91.0 dB | 约 4 秒 |

演练通过 10/10。

## 4K 正式导出耗时估算

- 1080p 导出实测每帧 0.075–0.097 秒（之前三段样片：1,380 帧 112 秒、1,020 帧 77 秒、360 帧 35 秒）。
- 4K 每帧按 3–4 倍算，每帧 0.23–0.31 秒，7,200 帧合计 **27–37 分钟**。
- 4K 编码：演练里 120 秒用 185.9 秒（源是 1080p 放大）；原生 4K 细节更多，约 **4–6 分钟**。
- assemble 其余步骤约 1.5 分钟。正式出片合计约 **35–45 分钟**。
- 磁盘：三个无损中间文件（4K qp0）估计 3–8 GB，16 GB 够用；assemble 跑完会自动删掉。
