## 二、旁白（画在 opening、film、ending 三页上）

- 新文件 src/frames/narration.ts：旁白时间表照方案 3.2 抄，时间按原片秒数。三页在每次 seek 时调用同一个渲染函数。
- 只有网址带 `&narration=1` 才显示。不带时三页输出必须和现在逐像素相同，所有现有检查照旧要过。
- 样式：
  - 整个 1920×1080 画面水平居中，文字块的竖直中线在 y = 964，和片尾那句「同一套对象，整个工厂一起用。」同一位置。
  - 中文字体同栏标题，26px，常规粗细，行高 1.45，正文深灰色，每条最多两行，按表里的 `<br>` 换行。
  - 底板：浅底色 85% 不透明，圆角 6px，内边距上下 8、左右 16，没有描边、阴影和发光。
- 动效：在区间 [a, b] 内显示。a 起 0.25 秒淡入并上移 6px，b 前 0.2 秒淡出。是 t 的纯函数。
- 检查（加到一个新脚本 scripts/check-narration.py）：
  - 每 0.1 秒取样，DOM 文字和表逐字一致。
  - 旁白框和其它任何可见文字元素的外接框都不相交，也不出画面。
  - 不带 narration=1 时，抽 30 个时刻和 072d37c 相比逐像素相同。
  - 带 narration=1 时，先跳到别处再跳回来，和直接打开相同。

## 三、标题卡（新页 frame=card）

- 网址 `frames.html?frame=card&id=N&theme=light&bg=<图片地址>`。时间 u 从 0 到卡长，`__start = 0`、`__duration = 卡长`，`__seek(u)` 和其它页一样。
- 背景：bg 指向一张 3840×2160 的 PNG，是插入点那一帧的定格画面，按 1920×1080 铺满。
- 7 张卡：
  - 片头 id 0，插在 0 之前，背景用原片 t = 0 那一帧。
  - id 1–6 依次插在原片 30.0、33.0、49.0、64.0、86.0、101.0 秒之前，背景用原片在该时刻的那一帧。
  - 卡长：id 0、1、6 是 2.4 秒，id 2–5 是 2.0 秒，合计 15.2 秒。成片 135.2 秒，8,112 帧。
- 文字照方案 2.1：小字标签、大字标题、副标题。id 4 标签里的「自动提示」用状态红，其余标签深灰。
- 样子照方案 2.2：
  - 浅色幕最多 80% 不透明。
  - 蓝色细线 #1c5fb8，宽 100px、粗 1.5px，在标签和标题之间。
  - 标签用等宽字体，约 20px，字距放宽。
  - 标题约 64px，中等粗细，深色。
  - 副标题约 24px，灰色。
  - 三层都在画面正中。
- 时间（卡长 D）：
  - 0–0.3 浅色幕从 0 到 80%；
  - 0.25–0.6 细线从中间向两边画出；
  - 0.45–0.95 标签和标题从左往右擦出；
  - 0.8–1.1 副标题淡入；
  - D−0.35 到 D，所有内容和浅色幕一起退到 0。
  - 片头那张例外：开始时浅色幕 100%（看不到背景），结束时同样退到 0。
- 要求：每张卡最后一帧和背景图逐像素相同（浅色幕为 0）。
- 声音事件：每张卡在 0.25 秒（细线开始）有一个 tone，gain 0.35。
