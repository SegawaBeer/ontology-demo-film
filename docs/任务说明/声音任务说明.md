# 声音任务说明：全片音效合成与混音

- 日期：2026-10-27
- 派活：演示规划与监工Agent
- 依据：脚本 v1.3（「脚本/本体演示视频脚本-v1.3.md」）里写到声音的地方；成片总计划。
- 产出目录：项目根目录「音频/」（已加入本地 git 忽略）。程序放在 film-main 工作副本的 `scripts/audio/` 下，提交到 film-main 分支。

## 一、原则

- 全部用程序合成，不用任何外部音频素材，不用文字转语音，不配人声旁白，不配有旋律的背景音乐。这样不涉及版权，也和「实时生成」的画面风格一致。
- 声音要克制、干净：短促的合成音，像精密仪器界面的提示音。不做游戏音效，不做电影预告片式的轰鸣和上扬音。
- 每个音由画面里的事件触发：事件表来自各页面的 `window.__events`（`{ t, kind, gain }`，t 是全局秒）。没有事件表的段落（开头 0–30 秒），按本说明第三节列出的时刻手写一张表。
- 输出 48 kHz、24 位、立体声 WAV。最后整体响度 −16 LUFS（积分），真峰值 ≤ −1 dBTP。

## 二、音色（用 Python + numpy 合成；装不了 numpy 就用纯 Python 写，速度慢一点也行）

| 名字 | 用在哪 | 做法 |
| --- | --- | --- |
| tone | 开头 0:00 叶片出现 | 正弦 660 Hz 加 1320 Hz（−14 dB），起音 8 ms，指数衰减 1.6 秒，轻微混响 |
| tick | 叶片补满一圈、压气机叶环套上 | 4 ms 的白噪声脉冲经 3–6 kHz 带通，加 2.2 kHz 正弦 20 ms 衰减；每次音高随机 ±3%，音量随机 ±2 dB |
| thud | 21.9 秒整机装完（脚本里的「一声重音」） | 55 Hz 正弦加 110 Hz（−10 dB），起音 5 ms，衰减 0.9 秒；加一层 200 Hz 低通的噪声 60 ms |
| spin | 风扇转动 | 低频持续音：基频 = 风扇叶片数 16 × 转速（转/秒），加 2、3 次谐波，加 400 Hz 以下的粉红噪声；音量跟转速走，停转时为 0 |
| type | 逐字打字 | 1.5 ms 噪声脉冲经 2–5 kHz 带通，衰减 25 ms；音量 −30 dBFS 左右，每个字随机 ±3 dB |
| line | 回答出现一行 | 正弦 880 Hz，起音 3 ms，衰减 120 ms，−24 dBFS |
| tick-num | 数字停在最终值 | 正弦 1320 Hz 加 1980 Hz（−8 dB），衰减 90 ms，−22 dBFS |
| path | 族谱一条线开始亮 | 正弦从 500 Hz 滑到 720 Hz，持续 0.25 秒，音量 −30 dBFS，起止淡入淡出 |
| slide | 对话框滑入滑出、镜头大移动 | 粉红噪声经 300 Hz–2 kHz 带通，音量包络和移动曲线的速度成正比，−28 dBFS |
| part | 零件移动或到位 | 金属轻碰：几个不成谐波的正弦（1.7、2.9、4.3 kHz），衰减 0.18 秒，−26 dBFS |
| swap | 叶片互换 | 两个 tone 交叉淡变，音量 −24 dBFS |
| alert | 问题三自动提示 | 两个短音：740 Hz、0.12 秒，间隔 0.16 秒，再来一个 740 Hz；−18 dBFS |

- 各音的 gain 乘上事件表里的 gain。
- 同一时刻事件过多时（每 50 毫秒超过 4 个），后面的音量按 1/√n 降低，避免叠成噪声。
- 立体声：族谱里的事件偏右（声像 +0.35），对话框偏左（−0.35），三维居中。

## 三、开头 0–30 秒的事件（手写，时刻照开头任务说明）

- 7.65–8.60 秒，补满一圈的 99 枚叶片，每枚一个 tick。时刻 t_k = 7.65 + 0.95 × √((k − 2)/98)，越来越快。

- 17.0–21.3 秒，每件零件出现时一个 part。风扇叶片 16 枚，每枚一个 tick。
- 21.9 秒 thud。

- 23.0–28.6 秒，每个节点淡入一个很轻的 line（−32 dBFS），每条关系开画一个 path。

## 四、混音和导出

- 程序 `scripts/audio/make_audio.py`：读事件表（开头那张手写表，加上各页面导出时存下来的 `__events`），合成，输出 `音频/全片音效.wav`。
- 事件表的取法：写一个小脚本，打开 `frame=film&play=0`，读 `window.__events`，存成 `音频/events-film.json`；开头的表存成 `音频/events-opening.json`。
- 混音时整体加一点短混响（预延迟 10 ms，衰减 0.8 秒，湿声 −18 dB），不加压缩器以外的效果。
- 导出一份 `音频/全片音效-预览.mp4`：把 1080p 样片和音轨合成，让我检查声画同步。

## 五、检查

- 每个事件的起音时刻和事件时刻相差 ≤ 5 毫秒（在波形上找起音点）。
- 响度 −16 ± 0.5 LUFS，真峰值 ≤ −1 dBTP（用 ffmpeg 的 loudnorm 或 ebur128 滤镜量）。
- 没有削波，没有直流偏移（均值绝对值 < 0.001）。
- 0–0.3 秒和 120 秒最后 0.5 秒是静音或渐出，片尾没有被截断的尾音。

## 八、第三轮：各类声音的音量平衡（2026-10-29 00:30）

第二轮通过（4209ad4，22/22）。报告里四条需要知道的事都照你的做法。

我量了「音频/全片音效-0-64秒.wav」各段的瞬时响度（ebur128 的 M 值，400 毫秒窗口，取每段最大值）：

- 21.9 秒重音 −12.7 LUFS。
- 23.5–26 秒风扇匀速 −8.8，25–27 秒族谱连线加风扇 −8.8，51.6–53.5 秒爆炸图展开 −7.8。
- 0.3 秒第一声 −9.6。
- 38–45 秒回答行 −15.9；打字 −27.5。

问题：脚本里 21.9 秒的「一声重音」应该是全片最突出的一下，现在风扇的持续低音、成串的族谱连线和爆炸图那几秒都比它响 4–5 LU。风扇低音是全片最响的持续声，接近第一节不让做的「轰鸣」。打字比回答行低将近 12 LU，用笔记本扬声器基本听不见。

### 8.1 目标（都是相对 21.9 秒重音的瞬时响度最大值，记作 T）

| 类别 | 瞬时响度最大值 |
| --- | --- |
| thud（21.9 秒） | T，全片最高 |
| alert（问题三提示） | T − 2 到 T − 4 |
| tone（0.3 秒、结尾 105、116.4 秒） | T − 3 到 T − 6 |
| line、tick-num | T − 5 到 T − 8 |
| part、tick（补叶片、风扇叶片） | T − 6 到 T − 9 |
| slide | T − 8 到 T − 11 |
| path，包括成串的时候（25–28.6、51.6–53.4、结尾 103 秒四条同时亮） | 不高于 T − 8 |
| spin（风扇匀速） | T − 10 到 T − 13 |
| type（一段连续打字） | T − 12 到 T − 15 |

- 「瞬时响度最大值」的量法：把这一类声音单独合成一条（其它类别静音，增益、密度降音、混响和正式混音完全相同，最后乘上正式混音的同一个归一增益），在这一类出声的时段里取 ebur128 的 M 最大值。T 也这样量。
- 这样量出来，同一时刻几种声音叠在一起时总的响度会比单独量的高。所以另加一条：正式混音里，21.9 秒之外任何时刻的 M 值都不能超过 T。
- 调法：在 `scripts/audio/` 里按类别加音量系数（只改声音程序，不改画面页面给的 gain），然后整体再归一到 −16 LUFS、真峰值 ≤ −1 dBTP。
- 风扇不要只降音量：把粉红噪声那一层在 150 Hz 以下再衰减 6 dB，让它听上去是「转动」，不是「轰」。

## 九、第四轮：重音不压扁（2026-10-29 05:10，以这一节为准）

第三轮的平衡表全部达到（d05200f）。但默认那一版里，21.9 秒的重音被峰值限制压成了一段 0.85 秒不衰减的低音：
- 在波形上是一整块。
- 每 0.1 秒的电平一直停在 −6 到 −8 dB。
- 这正是第一节不让做的「轰鸣」。

「重音不压」那一版衰减正常，0.5 秒内从 −6 降到 −28。决定如下。

1. **默认改成「重音不压」的做法**：任何时刻峰值限制的压缩量 ≤ 3 dB。
2. **取消整体 −16 LUFS 的要求**：
   - 整体响度由平衡表和真峰值 ≤ −1 dBTP 决定，预计在 −20 到 −22 LUFS 之间。可以接受的范围是 −23 到 −15。
   - 原因：这条音轨只有短促的提示音，没有人声和音乐。−16 是我当初照一般视频定的，和「重音要有自然衰减、又要最突出」做不到同时满足。
3. **重音换音色，让笔记本、会议室的小扬声器也听得到**（替换第二节表里 thud 那一行）：
   - 为什么要换：小扬声器基本放不出 200 Hz 以下的声音。现在的重音只有 55 Hz、110 Hz，在笔记本上几乎听不见，片子里最重要的这一下就没了。
   - 做法：
     - 在 55 Hz、110 Hz（−10 dB）上再加 220 Hz（−12 dB）、330 Hz（−18 dB）。几个谐波的相位选峰值最小的组合。
     - 起音处加一个 8 ms 的噪声瞬态，经 300 Hz–1.5 kHz 带通，比基音低 16 dB。
     - 原来那层 200 Hz 低通的 60 ms 噪声保留，衰减时间仍是 0.9 秒。
   - 好的音箱上听，它仍然要是一声低沉的重音，不能变成中高频的「咚」或「叮」。
4. **平衡表（8.1）不变**，T 仍是重音的瞬时响度最大值，量法照旧。
5. **新加小扬声器检查**：
   - 正式混音和各类别单独的音轨，都先经过 250 Hz 四阶高通（近似笔记本扬声器）。
   - 要求：重音的瞬时响度最大值不低于 line、tick-num 那一类。
6. **检查清单**：
