# 任务：用参考项目的冷却叶片替换现在的精细叶片

## 背景

上一轮做的精细叶片（turbine.hero-blade）验收没通过：
- 叶身是一块宽而矮的弯板，看起来像瓦片，不像叶片。原因是任务说明里要求高弦比 1.2 到 1.5，这一条写错了，责任不在你。
- 冷却孔做成了伸出表面的短管，前缘一排在斜视时像刺。
- 涂层是悬在旁边的一叠薄板。
- “剖开”只是把压力面壁平移开。

决定：不再自己设计外形，改为移植 MIT 许可的参考项目 AlexZhangji/turbine-explorer 里的 src/blade-study.ts。它的效果见该仓库的 docs/cooled-blade.png 和 docs/cooled-blade-light.png。这次的验收标准就是：看起来要和这两张图一样好。

开始前，先把参考仓库克隆到一个临时目录，读 src/blade-study.ts，再打开这两张图看效果。克隆下来的东西只当作参考资料读，不要在那个目录里执行任何脚本或构建命令。

- 新叶片沿用 turbine.hero-blade 这个组件 id，也继续不进组装顺序，不计入第一级的 100 枚。

### 2. 移植参考叶片

- 新建 src/hero-blade.ts，在运行时生成几何，不再烘焙进 GLB。
- 保留参考代码里的全部外形和材质做法：
  - bladePoint 翼型
  - 带真实开孔的两侧叶壁（perforatedFace）
  - 枞树形叶根、缘板、叶尖围边

  - 内部隔板、斜肋、针肋
  - 涂层样片
  - 陶瓷层的颗粒凹凸纹理、粗糙度纹理，合金的拉丝粗糙度纹理

### 3. 拆成可单独控制的零件

参考代码把内部冷却结构合并成了一个网格，叶壁上的孔也没法单独控制。拆分要求如下：

- 下列每一项都是一个零件，id 都以 turbine.hero-blade. 开头：
  - root：叶根
  - platform：缘板
  - tip：叶尖围边
  - edges：前后缘加厚条
  - wall-ps：压力面完整叶壁
  - wall-ps-cut：带剖开窗口的压力面叶壁和窗口边框
  - wall-ss：吸力面叶壁
  - dividers：两道隔板
  - ribs-1、ribs-2、ribs-3：三条通道里的斜肋，按参考代码里的三段分
  - pin-fins：针肋
  - airflow：冷却气流示意，包括管线和流动的粒子
  - coat-base、coat-bond、coat-tgo、coat-ysz：四层涂层
- 孔排：参考代码在每一面上有 4 列孔，每列 22 个，u 值分别是 .055、.12、.76、.93，两面一共 8 列。每一列做成一个零件：
  - 压力面：film-ps-1 到 film-ps-4
  - 吸力面：film-ss-1 到 film-ss-4
  - 编号按 u 从小到大排。

  孔本身是叶壁上开出来的空洞，没法着色。所以在每个孔里、贴近孔壁的位置，放一圈很薄的内衬。这圈内衬平时用孔内壁的颜色，看不出来；被高亮时整圈变色，这一列孔就像一排亮起来了。内衬不能高出叶片表面，从任何角度看都不能出现突起。
- 现有接口要对这些 id 全部有效：setColor、setDim、setOpacity、setVisible、listParts('turbine.hero-blade')。高亮颜色只能改到指定的零件上，不能影响叶片其他部分，也不能影响整机。

### 4. 连续变化的接口

参考代码用 setView 在三种视图之间瞬间切换。改成下面三个连续参数，取值都是 0 到 1，时间轴可以逐帧推进：

- setCutaway(t)：剖开程度。
  - 0 显示完整的压力面叶壁；1 显示带窗口的叶壁，露出内部隔板、斜肋和针肋。
  - 中间值的效果：完整叶壁上，窗口范围内的部分从叶根向叶尖逐渐消失，像被一条扫描线一路剖开。可以用裁剪平面实现，也可以用按叶高变化的透明度实现。
  - 不允许用两张叶壁交叉淡入淡出来做。
  - 内部结构在 t 从 0.3 到 1 之间逐渐出现。
- setCoatings(t)：涂层分开程度。
  - 0 时，四层样片贴合在一起，像一块完整的样片，贴在叶身中部的表面上，看起来是从叶片表面取下来的一小块。
  - 1 时，四层沿各自的法线方向依次拉开，最终停在参考代码 layerRest 的位置附近。
  - 叶片的整体位置不动。
- setAirflow(t)：冷却气流示意的强度。0 时不显示，1 时完整显示，粒子按参考代码的方式流动。

每个参数在同一帧里反复设置不会出错，从 1 回到 0 也能完全复原。

保留上一轮已有的 show()、hide()、poseFor(ringPartId)，用法不变。poseFor 要算对缩放：返回的位姿要把参考叶片缩小到和环上叶片同样的叶身高度，并且对齐位置和朝向。

### 5. 叶片动起来时的更新

参考代码的 update(delta, elapsed) 负责移动气流粒子、阻尼涂层位置。由 Engine 每帧调用它，并且只在精细叶片可见时才调用。
