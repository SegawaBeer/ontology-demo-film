## 三、已定的处理

- **转子（三B 实施）**：22.0–23.2 秒加速，之后匀速，26.0–28.0 秒减速到停。θ(28.0) 正好是 360°，所以 28 秒以后静止，和样式图、交接画面一致。
  - 积分 = 0.6 + 2.8 + 1.0 = 4.4，所以 ω = 360/4.4 ≈ 81.82 度每秒（替换三A 的 360/5.4）。
  - 减速段速度因子取 1 − smootherstep((t−26)/2)。
  - 结尾风扇再转起来时另行定义。
- **气流（三B 和结尾）**：风扇转动期间，沿发动机轴线画淡灰蓝细流线，从进气口经外涵道和核心机流向尾喷口。流线强度随转速变化，静止时完全消失。不发光、不做粒子拖尾，是 t 的纯函数。
- **三B 的 28–30 秒**：
  - 28.0 秒对上样式图。
  - 28.0–28.6 秒「库存 → 第一级涡轮叶片」从 42% 画完，计数变「34 / 34」，叶片节点扩一圈，左边第一级叶环闪一下。
  - 28.8–29.4 秒 PO-26-1187 标注淡出，燃烧室高亮退回本色。
  - 29.5–30.0 秒静止，等于交接画面。
- **精细叶片互换**：精细叶片比环上叶片宽、扭转方向相反，近景互换会穿帮。凡是在环上叶片和精细叶片之间切换，都只能在叶片离开叶环足够远，或镜头拉远到整圈时，用约 1 秒颜色过渡加交叉淡变完成。开头 5–7.6 秒就是这样做的。
- **三栏宽度**（照问题三样式图）：对话框约 562 像素，三维约 718 像素，族谱 640 像素（1920×1080 下）。
- **不出现**：平台标识、「转子」节点、发光光晕、景深、镜头光晕、慢动作。
