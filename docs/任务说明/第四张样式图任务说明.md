## 四、0:00–0:05 的时间关系（这一帧取 t = 3）

这一帧要做成按时间 t（秒）计算的，URL 用 `frames.html?frame=open&theme=light&t=3`。不写 t 时默认 3。以后做开头动画时直接沿用。
- 轮廓线淡入：轮廓线不透明度 = smoothstep(0, 1.2, t)。
- 铺材质：从叶根往叶尖扫，进度 s = smoothstep(0.6, 2.2, t)。扫过的部分显示正常材质、不再画轮廓线；没扫到的部分只有轮廓线、没有材质。扫描前沿不加发光，不加亮线。
- 节点出现：t 在 1.0–1.4 之间从无到有。之前右栏计数写「0 个节点 · 0 条关系」。
- 细线：画出比例 p = clamp((t − 1.8) / 1.4, 0, 1)，匀速，不加缓动。t = 3 时 p ≈ 0.86，线头越过中线约一百四五十像素、还没到节点，这正是要定格的瞬间。t = 3.2 时画完。
- 叶片转动：绕叶片自身竖直轴匀速转，每秒 8°。yaw(t) = Y3 + 8 ×(t − 3)，Y3 是 t = 3 时的角度，由第五节选出。
- 调试用参数（可覆盖上面的计算结果）：`&sweep=0..1`、`&thread=0..1`、`&yaw=度数`、`&mask=1`（见第七节）。

t = 3 时 s = 1，所以样式图本身是材质铺满、没有轮廓线的完整叶片。轮廓线和铺材质在 t = 0.6、1.2、1.8 三张检查图里看（第八节）。

## 五、叶片转到什么角度（Y3 怎么定）

上一版精细叶片被打回过一次，原因是看起来像「带孔的弯板」。这次的角度要让人一眼看出是一枚涡轮叶片：叶身弯曲看得见，冷却孔排看得见，不能正对着薄边（像根柱子），也不能正对着大面（像块平板）。

用数值选，不要凭感觉：
1. `src/hero-blade.ts` 导出了 `bladePoint(u, t, face)` 和 `outwardNormal(u, t, face)`，可以直接 import 来用（只读，不改这个文件）。u 从前缘 0 到后缘 1，t 从叶根 0 到叶尖 1，face = 1 是压力面。法线和点都要乘上叶片在场景里的世界矩阵。
2. yaw 从 0° 到 355°，每 5° 一个候选。每个候选在 t = 3 的姿态下算三个数：
   - A = 压力面中部（u = 0.5，t = 0.5，face 1）的世界法线，与「从该点指向镜头」的单位向量的点积。
   - B = 前缘孔排处（u = 0.08，t = 0.5，face 1）同样的点积。
   - R = 叶片在 mask 图里的外接框宽 ÷ 高。
3. 合格条件：A ≥ 0.35，B ≥ 0.25，0.30 ≤ R ≤ 0.48；并且同一个 Y3 下，t = 0 和 t = 5 两个姿态的 R 都 ≥ 0.22（保证 5 秒里任何时刻都不正对薄边）。
4. 合格的候选里取 min(A, B) 最大的那个作为 Y3。
5. 把全部 72 个候选的 A、B、R 写进 `review/style-frames/yaw-candidates.csv`，报告里写选中的 Y3 和它的三个数。
6. 如果一个合格的都没有：不要放宽条件，不要硬选。把 csv 和你认为最接近的三个候选写进报告，发消息给监工，停下。
