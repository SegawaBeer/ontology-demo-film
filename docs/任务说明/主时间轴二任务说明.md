  - 回答行、方案卡片：每行或每张卡片一个 line。
  - 数字停下：一个 tick。
  - 族谱：每条线开画一个 path。
  - 叶片：每枚飞进来的叶片落座时一个 part。
  - 98.6 秒问题二答案变绿：一个 line。
- 结尾：
  - 101.0–103.0 对话框滑出、镜头回分屏：一个 slide，时长 2.0。
  - 103.0 四条路径重新亮起：每条一个 path。
  - 105.0 叶环和叶片节点闪：一个 tone，gain 0.5。
  - 112.0–115.0 叶片互换：一个 swap，放在交叉淡变开始的时刻。
  - 116.4 字幕淡入：一个 tone，gain 0.8。
- 风扇声不用记事件。声音程序按 9.5 的转速公式自己算。
- F13 的检查范围扩到 30–120 秒。

声音程序由另一个子任务在单独的分支上写，它只读 `window.__events`，不读你的代码。所以事件的 kind 只能用上面这些和主时间轴一已经用过的。

## 十、30–120 秒中途验收（2026-10-29 13:00，监工）

我在「样片/主时间轴-30-120秒-1080p.mp4」里看了 64–120 秒的 32 个时刻，大部分是对的：
- 问题三接得上。
- 问题四：对话框的字、两张方案卡片、光标、「到位 n / 16」、沿树走的路径、库存两行标注、计数 35 · 36、叶片落座、问题二变回绿色，都对。
- 结尾：对话框滑出、四条路径重新亮起、淡出的先后、计数倒数到「1 个节点 · 0 条关系」、「×1」、字幕位置，都对。
- 120 秒看上去和开头 4.0 秒一样。

下面五处要改。

### 10.1 问题二变回绿色时，时间写错了

- 现象：98.6 秒以后，问题二上方的标记变成绿色的「自动更新 · 02:17」。02:17 是它变红的时间，变绿是问题四执行调拨的时候，也就是 02:24。
- 改法：
  - 98.6–98.8 秒，旧标记「自动更新 · 02:17」淡出。
  - 98.8–99.0 秒，在同一位置淡入绿色的「自动更新 · 02:24」。
  - 任何一帧不能两份同时可见，照主时间轴一 12.1 的口径。

### 10.2 粉末批次的标注应该是绿色

- 现象：92–93.4 秒「YSZ-2398 · YSZ-2421」是深灰色。
- 要求：照 9.1 改成绿色（状态绿）。红色外圈闪一下照旧。

### 10.3 零件淡没以后，气流还悬在空中

- 现象：106–110 秒，风扇、进气罩、尾喷管已经淡出，它们前后的气流线还在，飘在空白里。
- 改法：每一段气流线的不透明度，再乘上它旁边那个零件当时的不透明度。零件没了，气流也没了。
  - 进气口前那一段，乘风扇和进气罩里不透明度较高的那个。
  - 外涵道出口后那一段，乘外涵道机匣的不透明度。
  - 尾喷口后那一段，乘尾喷管的不透明度。

### 10.4 结尾叶片太小，画面空了三秒

- 现象：其余零件淡没以后，镜头还停在整机取景。110.5–113.8 秒，三维栏里只有 001 号一个小点，在 1080p 下约 15 像素高。观众看不出这是一枚叶片。
- 改成镜头分两段走：
  1. 109.0–111.4：从整机取景推到「整圈叶环」取景。
     - 观察方向不变。
     - 第一级涡轮叶环整圈都在画面里，外径约为三维栏高度的 55%，叶环中心在栏中间附近。
     - 淡出照常进行，先后顺序不变。环上的相邻叶片最后淡，112.0 秒时除 001 号外全部没了。
  2. 互换：颜色过渡和交叉淡变放在「整圈叶环」取景的时候做，112.6 秒前做完。这时整圈都在画面里，符合用户定的「拉远到整圈再换」。
  3. 112.6–115.0：从「整圈叶环」取景推到开头 t=3 的镜头。001 号离开叶环，回到 t=3 的姿态和自转角度。
- 三维栏标题仍在 112.0–112.3 秒换字。
- 检查：
  - 110.5 秒以后，001 号在画面上的高度不小于 50 像素。
  - 两段镜头都照 F11 查曲线，起止速度 ≤ 中位数的 0.2 倍。
  - 互换过程没有形状跳变，照 F9 查。
  - G4（120.0 秒等于开头 4.0 秒）照旧要过。

### 10.5 开头和结尾，细线从「第一级涡轮叶片」这几个字中间穿过

- 现象：
  - 开头那条从叶片连到节点的细线，大约 3.2 秒画到节点以后，正好从「第一级涡轮叶片」几个字的中间横穿过去，看上去像删除线。
  - 结尾 116.4–120 秒也是一样，因为 120 秒必须等于开头 4.0 秒。
  - 这是全片第一个和最后一个镜头。
- 改法：
  - 只给这一个节点名加一圈「底色描边」：用 SVG 的 paint-order 先画描边，描边颜色等于族谱栏的底色，宽 4–5 像素，节点名画在细线上面。这样线看上去是从字的后面穿过去。
  - 只在 open、opening 两个帧和结尾用，其它地方的节点名不变。
- 要求：
  - 开头 3.0 秒（第四张样式图那一帧）逐像素不变，那时线还没画到字。
  - 120.0 秒仍然等于开头 4.0 秒。
  - F1 把开头里因此变化的帧和像素范围列成例外。
  - 重出「样片/开头-0-30秒-1080p.mp4」，导出地址带 `&play=0`。
- F15 也在 frame=opening 0–23 秒跑。亮线压节点名的，照 12.2 只列出来，写进报告，我来定。

### 10.6 顺序

1. 现在后台在跑的那一轮检查，让它跑完，跑的过程中不要改任何文件。开发服务器给的是实时代码，中途一改，结果就混了。
2. 跑完以后，把 10.1–10.5 和这一轮检查里没过的项一起改。
3. 重跑全部检查（F1–F15、G1–G6）。
4. 重出 30–120 秒样片和开头 0–30 秒样片，写报告。
