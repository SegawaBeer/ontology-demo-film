# 任务：做一枚用于特写镜头的精细涡轮叶片，并调整涡轮的组装顺序

## 背景

model-split 分支上的拆分和返工都已验收通过。返工报告在 review/model-split/返工报告.md，开始前先读一遍。

验收时确认了一点：第一级环上的 100 枚叶片受叶根节距（约 0.019）限制，弦长做不大，叶高和弦长之比约 2.9，单独放大看像一根柱子；真实高压涡轮叶片的这个比值约 1 到 1.5。环上的叶片在整机画面里没有问题，保持现状，这次不改。

视频里叶片单独出现或被放大的镜头有四处：
- 开头：一枚叶片单独出现在空白背景上，慢慢转动。
- 问题一：从环里抽出一枚叶片，转到冷却剖面，叶片上的冷却孔一排一排亮起来。
- 问题三：一枚叶片放大，四层涂层分开，最外层的陶瓷层变红。
- 结尾：画面里只剩一枚叶片，和开头一样。

这四处统一用一枚单独制作的精细叶片。它和环上的叶片在镜头切换时互换，所以两者形状不必完全一致，但位置和朝向要对得上。

## 要做的事

### 1. 外形

- 比例：叶身高度和弦长之比 1.2 到 1.5。
- 叶身截面：前缘圆而厚，尾缘薄，弯度明显（压力面凹、吸力面凸）。安装角 30° 到 40°，从叶根到叶尖扭转 10° 到 20°。截面点数和沿叶高的分段都要足够多，放大到全屏也看不出折角。
- 叶尖：一圈凸起的围边，中间下凹（叶尖凹槽）。
- 缘板：比叶身截面宽一圈的平行四边形，方向顺着安装角。
- 缘板和叶根之间有一段较窄的颈部。
- 叶根：3 道齿的枞树形，左右对称。
- 尾缘：沿叶高有一排劈缝出口。
- 可以参考 MIT 许可的 AlexZhangji/turbine-explorer 仓库里的 src/blade-study.ts，移植后修改，并在 THIRD_PARTY_NOTICES.md 里注明来源。

### 2. 冷却结构

- 内部至少三条来回折返的冷却通道，通道里有斜肋，靠近尾缘处有一片针肋。
- 表面气膜孔分成若干排，每一排是一个可以单独控制的对象：
  - 前缘喷淋孔 3 到 4 排
  - 压力面气膜孔 2 排
  - 吸力面气膜孔 1 到 2 排
  - 尾缘劈缝 1 排
- 孔要真的开在壁上，看得到孔洞，不能只是贴在表面的圆点。

### 3. 涂层

- 四层材料，从里到外：镍基高温合金基体、金属粘结层、热生长氧化层、陶瓷热障层。
- 做法参考 blade-study.ts 里的“放大涂层样片”：从叶身表面取一小块，四层可以沿法线方向分开。层厚可以夸大，但四层的厚度要看得出相对关系：陶瓷层最厚，氧化层最薄。
- 每一层都是一个可以单独控制的对象。中文名用上面的叫法，不用厂商术语。

### 4. 运行时接口

在现有接口之外新增一个精细叶片对象，要求如下：

- 视图切换用连续参数控制，参数从 0 到 1，时间轴可以逐帧推进，不要做成只能瞬间切换的开关：
  - 剖开程度：0 是完整外观，1 是沿弦向剖开、露出内部通道
  - 涂层分开程度：0 是四层贴合，1 是四层完全分开
- 每排气膜孔、每条冷却通道、每层涂层，都能用现有的按 id 操作的接口来设颜色、变暗、设透明度、显示和隐藏。id 按原来的规则起，例如 turbine.hero-blade.film-row-1、turbine.hero-blade.coat-ysz。
- 提供一个函数：传入环上某一枚叶片的 id，返回一个位姿，把精细叶片放到这枚叶片的位置和朝向上，并缩放到叶身高度和它一致。时间轴会用它来做两者的互换，比如开头叶片落到轮盘上的那一刻。互换时的过渡动画不用做。
- 精细叶片默认隐藏，不参与整机的组装顺序，也不计入第一级叶片的 100 枚。

### 5. 组装顺序的小调整

返工后的组装第 3 步里包含了涡轮外环带（turbine.band）和涡轮内锥壳（turbine.inner-cone）。从截图 assemble-3.png 看，这两样会把第二到五级叶片整个包住；而脚本里，这一段要让观众看到第二到五级叶环一级一级套上去。

把这两个组件移到第 7 步“核心机机匣”。第 3 步只留第一到五级的叶片、轮毂、叶尖环和外环叶栅。改完之后重拍组装第 3 步和第 7 步，第 3 步从斜 45° 方向要能看到五级叶片。
