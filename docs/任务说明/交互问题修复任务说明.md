# 任务：修复 3D 发动机程序里的两个交互问题

## 背景

- 项目目录：<项目目录>，git 仓库，当前分支是 model-split。技术栈 Three.js + TypeScript + Vite。
- 程序入口是项目根目录的 index.html，主要代码在 src/main.ts（视图、镜头、点选、单独显示）和 src/model.ts（按零件 id 控制的接口）。
- README.md 里有接口说明，开始前先读一遍。
- 用户反馈了下面两个问题。

## 问题一：查看某些部件时，视角拖不动，松开鼠标就弹回去

现象：选中某个部件之后，按住鼠标拖动可以转视角；可是一松开，视角又自动回到拖动之前的位置。

线索：src/main.ts 里，镜头会朝一个目标位置自动移动（cameraGoal、cameraAnimating），每帧向目标靠近，直到距离小于 0.01 才停下。只要没停下，用户拖到哪里都会被拉回去。“距离小于 0.01”这个条件在镜头离部件很近、或者目标不可达时可能永远满足不了。具体原因请你自己查清楚，不要只按这条线索猜。

要求：
- 用户一开始拖动、缩放或平移（OrbitControls 的 start 事件），自动移动就立刻停止，以用户操作为准。
- 自动移动要在有限时间内结束，不能依赖一个可能永远达不到的距离条件。
- 点选部件、切换视图（完整外观、剖面、爆炸）、单独显示、返回整机时，镜头仍然会平滑移到合适的位置。

## 问题二：最小的零件没法单独查看

现象：点中一枚叶片之类的最小零件后，只在信息面板里显示出名字，没法单独看这个零件。

要求：
- 选中任意一个零件（例如一枚第一级涡轮叶片、一个螺栓）后，信息面板里有“单独显示”。点了之后：
  - 整机的其余部分全部隐藏，只留这个零件；
  - 镜头对准它，并缩放到让它占满画面的大部分；
  - 可以自由旋转、缩放查看。
- 再点“返回整机”，所有零件恢复原位、原样，镜头回到整机视角。
- 成圈的零件（比如叶片）在底层是共用一个网格的，单独显示时不能把同一圈的其他零件一起显示出来，也不能把它们永久藏掉。模块级的“单独显示”要照常可用。
- 检查一下点选：点到叶片时，应该选中这一枚叶片，而不是选中它所属的整个模块。
- 第一级涡轮叶片有一枚专门做特写的精细叶片，对应 src/hero-blade.ts。它不参与这次的点选，也不要改动它。

## 怎么验证

用本机 Chrome 无头模式来点、来拖、来截图。Python 的 playwright 已经装好，启动方式：

```
p.chromium.launch(channel='chrome', headless=True, args=['--use-angle=metal', '--enable-gpu', '--ignore-gpu-blocklist'])
```

视口设为 1440×900。开发模式下页面上有一个 window.__app，里面可以拿到 engine、camera、controls，用来读镜头位置。

需要验证的场景：
- 选中一个模块，等镜头移动完，用鼠标拖动转一个角度，松开后等 2 秒，读镜头位置，确认没有弹回去。
- 选中一个模块，在镜头还没移动完时就开始拖动，确认自动移动立刻停止。
- 点中一枚第一级涡轮叶片，点“单独显示”，截图，确认画面里只有这一枚叶片、而且占满画面；拖动转一圈再截一张。然后点“返回整机”，截图，确认整机完整、同一圈的叶片一枚不少。
- 对一个螺栓、一个压气机叶片重复上一条。
- 完整外观、剖面、爆炸三种视图各截一张，确认没有被这次修改影响。

截图存到 review/bugfix/ 下（review 目录不会被 git 跟踪）。截图先用 PIL 缩到 900 像素宽再看，每张只看一次。
