# 返工任务：修正模型拆分中影响视频镜头的几处问题

## 背景

model-split 分支上已经完成了涡扇发动机的拆分：9 个模块、40 个组件、2,021 个零件。报告在 review/model-split/报告.md，原任务说明在 任务说明/模型拆分任务说明.md，开始前两份都先读一遍。

这次在同一分支上继续修正，不推倒重来。零件 id 规则、运行时接口和数据清单格式都保持不变，只改下面列出的内容。下面每个问题都是从 review/model-split/ 里的截图和数据清单里查出来的，每条都写了现象、要求和验收方式。

## 必须修正

### 1. 重做第一级涡轮叶片的外形

现象：在 04-single-blade.png 里，单独一枚叶片是一根细长、截面弯曲的金属条，立在一个方块上，看不出是涡轮叶片。原因是叶片太窄：轴向只有约 0.016，径向约 0.146，宽和长之比约 1:9，而真实高压涡轮叶片的弦长接近叶高的一半。视频的开头和结尾都是这枚叶片单独出现，所以这一条最重要。

要求：
- 数量仍是 100 枚。id、编号顺序、局部原点（叶根中心）、局部 +Y 沿径向向外，这几条都不变。
- 加大弦长。轴向投影宽度大致和第一级叶尖外侧那圈细环（现名 turbine.stage-1-disc，x 从 −1.378 到 −1.341）一样宽，约 0.035 到 0.04。叶片带安装角，翼型弦线和发动机轴线约成 30° 到 40°，实际弦长约 0.045 到 0.05。叶片不能碰到第二级叶片，第二级从 x≈−1.444 开始。
- 翼型：前缘圆而厚，尾缘薄，弯度明显（压力面凹，吸力面凸），从叶根到叶尖有扭转。截面点数要足够多，近看不能有折角。
- 叶身下面是缘板，缘板下面是带 2 到 3 道齿的枞树形叶根，不要做成方块。
  - 缘板做成平行四边形，方向顺着叶片的安装角。轴向比叶身前后各宽出一点，切向宽度等于这一圈叶根处的节距（2π × 0.304 ÷ 100，约 0.019）。这样 100 枚排成一圈时，相邻缘板正好首尾相接。
  - 叶身截面在切向超出缘板是正常的，涡轮叶栅本来就是相邻叶片互相遮挡，但相邻叶身之间不能相碰。
- 叶根插进叶片内侧的轮毂。被轮毂挡住的部分可以和轮毂重叠，露在外面的部分不能和任何零件穿插：叶尖外侧的细环、第一级外环叶栅、第二级叶片都算。
- 材质不在这次的范围内，保持现有材质。

验收：
- 单独一枚叶片放在画面中央，白色背景和深色背景各拍一套，每套三个角度：正对压力面、正对前缘、斜上方 45°，共 6 张。每一张都要一眼能认出是涡轮叶片。
- 另拍一张整圈 100 枚叶片的特写。

### 2. 拆开那块贯穿全机的黑色薄壳

现象：combustor.casing.001 从 x −1.895 一直延伸到 2.047，几乎和整台发动机一样长，r 从 0 到 0.661。报告里把它称为“贯穿全机的黑色薄壳”，它被整个归进了燃烧室。从 12-assemble-6.png 可以看出，这个零件把尾喷管的锥体、核心机的过渡段、风扇后面的喇叭口全都连在一起。后果有三个：
- 组装到第 6 步“燃烧室”时，尾锥和风扇后面的喇叭口提前出现了；
- 问题二里“燃烧室组件半透明、闪烁”时，会连同尾部和前部一起半透明；
- 爆炸图里，燃烧室会拖着一根贯穿全机的黑管子。

要求：
- 把这个零件沿 x 方向切成几段，每段归到对应的模块。切口位置按几何上的明显分界来定：直径突变处、锥面和柱面的交界处。大致应该得到这几段：
  - 尾锥，归 exhaust，组件名“尾锥”
  - 涡轮内侧的锥壳，归 turbine 或 exhaust
  - 核心机内壁，归 core-casing
  - 燃烧室内壳，留在 combustor
  - 压气机前面的喇叭口，归 compressor 或 fan
  
  每段的归属写进报告，并说明理由。
- 切开后三角形不能丢失，切口处不能出现肉眼可见的缝。允许把跨越切口的三角形整个分给某一段，也允许沿切口重新剖分三角形。
- 这个零件是由 2 个原始连通块组成的。审计规则相应改为：每个原始三角形恰好属于一个零件。verify-model.mjs 同步修改，并检查被切开的三角形没有遗漏，也没有重复。
- 切完后检查 combustor 模块剩下的零件，它们的轴向范围都应当落在 x −0.5 到 0.5 附近。超出这个范围的零件列进报告。

验收：组装第 6 步截图里只有燃烧室，没有尾锥和前面的喇叭口；燃烧室单独半透明的截图里，只有燃烧室是半透明的。

### 3. 涡轮“盘”的归属和组装顺序

现象：
- 现在叫“第一级涡轮盘”的零件（turbine.stage-1-disc.001），r 只有 0.449 到 0.458，正好在叶尖外侧，其实是叶尖外面的一圈细环，不是轮盘。
- 叶根内侧 r≈0.30 的那圈鼓筒（turbine.stage-2-disc.002，x 从 −1.471 到 −1.341）横跨第一、二两级，却被算作“第二级涡轮盘”。所以第一级叶根下面没有属于第一级的盘。
- 脚本开头的镜头是：叶片一枚接一枚落到涡轮盘上，补满一圈。按现在的组装顺序，第 2 步出现的是叶尖外侧的细环，叶根下面是空的。

要求：
- 二到五级名叫“涡轮盘”的零件也按同样的标准检查一遍：
  - r≈0.45 的叶尖外环，改名为“第 N 级叶尖环”；
  - r≈0.30 一带的鼓筒，改名为“第 N 级轮毂”，按实际几何分到对应的级。
  
  一个鼓筒如果横跨两级，按它的轴向主体所在的级归属，并在报告里说明。组件 id 可以改，清单和 README 要同步更新。
- 组装顺序改为：第一级涡轮叶片 → 第一级轮毂 → 第一级叶尖环和外环叶栅 → 第二到五级 → 后面不变。
- 第一级叶根下面要能看到一个轮毂，叶片看起来是插在它上面的。如果现有几何只是一圈很薄的筒壁，叶片插在上面不像回事，就用代码生成一个简单的轮盘：带轮缘、辐板和中心孔，位置放在叶根下面。把它作为“第一级涡轮盘”单独成一个组件，并在报告里说明。

验收：重拍组装第 1、2、3 步。第 1 步只有 100 枚叶片；第 2 步多出叶片内侧的轮毂或轮盘，叶片看起来插在上面；第 3 步多出外侧的环。

### 4. 局部设透明度的零件不能停转

现象：报告里写着，“被平移或单独设透明度的零件会自动提升为独立网格，因此不会再跟着转子转”。被平移的零件不转，这是对的。但如果只给转子里一部分零件设透明度，比如一圈叶片里的几枚，这几枚会停下不转，其余的照常转，运转时画面就会出错。

要求：
- 只设透明度、没有被平移的零件，必须继续跟着所在的转子转。可以把它挂到转子组件下面，也可以每帧同步转子的角度，具体做法由你决定。
- 被平移的零件保持现在的做法：不跟转子转，但跟整机一起移动。时间轴程序以后会旋转整台发动机来变换展示角度。
- 写两个调试状态，各截第 0 秒和运转 5 秒后的两张图：
  - 抽出 16 枚叶片：两张图里这 16 枚的位置和角度完全一样。
  - 第一级叶环里 16 枚设半透明：两张图里这 16 枚跟其余叶片一起转过了同样的角度。

### 5. 尾喷口螺栓多出来的那 1 个

现象：exhaust.bolts 这一圈有 65 个，比相邻那圈 64 个的螺栓多 1 个。

要求：找出多出来的那一个是什么零件。如果是支架或其他零件，就移到正确的组件，让这一圈正好是 64 个；如果确实是螺栓，保留并在报告里说明。按 θ 重新编号，verify-model.mjs 里加上这一圈的数量检查。

## 顺带处理

- 帧率实测：上次是在后台标签页里用强制同步渲染算出的单帧耗时，不是真实帧率。这次在前台可见的窗口里，1920×1080、两台发动机同时运转，连续跑 10 秒，记录平均帧率和最低帧率。如果预览窗口拿不到前台，就用无头浏览器，并关掉后台节流，例如 Chrome 的 --disable-background-timer-throttling 和 --disable-renderer-backgrounding，然后说明用的是哪种方式。
- 上次截图里有几处是靠隐藏其他模块才看清的，比如红色的 16 枚叶片。这次的截图照旧这样处理就行，不用想办法让叶环从机匣外面透出来。透出叶环的问题由后面的视觉设计环节解决。
