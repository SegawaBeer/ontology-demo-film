## 二、从参考代码移植了什么、改了什么

## 四、三个连续参数中间值的做法

- 剖开（setCutaway）：完整压力面叶壁上，窗口范围内、扫描线以下的部分不再绘制，扫描线随参数从叶根升到叶尖，像一路被剖开；窗口边框也只画到扫描线的高度。参数到 1 时，扫描线已经越过叶尖，这时换成带窗口的叶壁。两者窗口外的形状和孔完全一样，所以这一下看不出跳变，也没有两张墙互相淡入淡出。隔板、斜肋、针肋在 0.3 到 1 之间由透明变为不透明。阴影也跟着一起被剖开。
- 涂层（setCoatings）：0 时四层是一块贴在叶身中部压力面上的小样片，形状顺着叶面弯曲，底面埋在叶壁里，顶面比叶面高出约叶壁厚度的一倍，看起来是表面上的一块。剖开时这块样片随叶壁一起被剖掉。参数增大时，陶瓷层最先离开，其余三层依次跟上；每层先沿叶面法线抬起，再移到参考代码的停放位置，形状同时从贴合叶面的弯片变回参考代码的样片形状。叶片本身不动。
- 气流（setAirflow）：管线和粒子的透明度随参数从 0 升到 1，0 时整组隐藏。粒子的流动方式和参考代码一样，由整机每帧推动，只在叶片可见时推动。

三个参数在同一帧里重复设置结果一致，从 1 回到 0 后所有可见状态、颜色、透明度、涂层位置都和初始状态逐项相同，页面自检逐项比对过。

## 五、孔排高亮的做法，以及侧面会不会露出内衬

每个孔里放一圈很薄的套筒：从叶面以下一点点开始，顺着孔壁往里收窄，一直伸到叶壁内侧。它的位置按叶壁自己的坐标算，所以和孔严丝合缝，不会在弯曲处偏出去。平时套筒用孔内壁的颜色，看不出来；上色后整圈变色并自发光，整列孔就亮起来。

侧面看不会露出：自检逐点量过，所有内衬的最高点都在叶面以下（最高处离表面还有千分之一个单位，叶身高 3.6 个单位）。rows-edge.png 是贴着表面斜看的画面，亮起的内衬只在孔里显出一道月牙形的内壁，轮廓外没有任何东西突出。

压力面第 3 列孔落在剖开窗口里，剖开时这一列跟着叶壁一起被剖掉；其余 7 列在剖开后都还在。

## 六、用法示例

开头：叶片出现，然后落到第一级 001 号叶片的位置。

```ts
const hero = engine.hero;
hero.poseFor('turbine.stage-1-blades.001');   // 记下目标叶片并显示
hero.setLanding(0);                            // 先停在发动机外侧、该叶片正上方
engine.setVisible('turbine.stage-1-blades.001', false);
// 时间轴每帧：t 从 0 推进到 1，叶片缩小并落到 001 号叶片上
hero.setLanding(t);
```

起始位置在机匣外面、001 号叶片的正上方，叶身约 0.36 高，相机对准它就是画面中央；落定后叶身高度、叶尖半径和中段朝向都和 001 号叶片一致，并且跟着转子转、跟着拆解移动。环上互换的两张截图里，远景相机离发动机轴线约 2.1；近景约 0.72，比该轴向位置的机匣（最大半径 0.69）更靠外。

问题一：剖开叶片，孔一列一列亮起。

```ts
hero.setCutaway(t);                            // 每帧推进，0 到 1
const columns = ['film-ps-1', 'film-ps-2', 'film-ps-4', 'film-ss-1', 'film-ss-2', 'film-ss-3', 'film-ss-4'];
columns.forEach((id, i) => {                   // 第 i 列在第 i 个节拍亮起
  if (beat >= i) engine.setColor(`turbine.hero-blade.${id}`, '#39d0ff');
});
// 第 3 列在窗口里，要它亮就在剖开之前亮
```

问题三：涂层分开，陶瓷层变红。

```ts
hero.setCoatings(t);                           // 每帧推进，0 到 1
engine.setColor('turbine.hero-blade.coat-ysz', '#e03b2f');
```

调试画面：?debug=hero，可加 bg=dark|light、cut、coat、flow、rows=ps|ss|all|ps1…ss4、ceramic=1、angle=front|back|zoom|edge、pose=001、shot=far|near。自检：?debug=hero-check，结果直接显示在页面左上角。

## 八、自检结果

页面自检全部通过：25 个 id 都能取到；每个 id 上色后只有它自己变色，整机颜色不变；调暗、透明、显隐都能恢复；三个参数 0→1→0 后完全复原；同一帧重复设置结果一致；内衬不高出表面；旧零件 id 不再存在；放到 001 号叶片上时叶身高 0.1260（环上 0.1260）、叶尖半径差 0.0005、轴向偏差 0；复位后叶片隐藏并回到初始状态。npm test 和 npm run build 都通过。

## 九、没做到的地方和原因

1. 和参考图仍有细微色差，见第二节末尾。原因是参考项目的灯光不在允许读的范围内，只能对着截图取色调。
2. 参考代码里“选中涂层后滑出并描边”的交互没保留，原因见第二节第 6 条。如果镜头需要这个效果，可以在时间轴里自己移动该层。
3. 放到环上时，精细叶片和环上叶片形状对不齐，有两处：
   - 精细叶片更宽：叶身高度一致，但中段弦长多约 22%，缘板切向宽度约为叶片间距的三倍，所以缘板和左右邻居的缘板重叠（swap-near.png 能看到）。
   - 扭转方向相反：参考叶片从叶根到叶尖安装角变大，环上叶片是变小。对齐的是叶身中段，所以叶根和叶尖各差约 18°。
   这两处都来自参考叶片本身的外形，按要求不改外形，只对齐了叶身高度、位置和中段朝向。如果近景要紧贴邻居，需要决定是否在互换时隐藏 001 两侧的叶片；扭转方向如果要一致，只能改参考外形或改环上叶片，需要人来定。
4. 环上互换的两张图用的是整机自己的灯光，精细叶片的陶瓷层在这套光下比环上的金属叶片白，颜色差别明显。
5. 完整外观图里叶身中部能看到一个浅浅的矩形轮廓，那是贴合状态的涂层样片，按要求 0 时要贴在叶面上。如果某个镜头不想看到它，可以单独隐藏四个涂层零件。
