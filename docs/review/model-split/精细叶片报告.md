## 三、涂层

四层样片放在叶片旁（+Z 方向 0.075 起），从里到外：`coat-base`（镍基高温合金基体，厚 0.010）、`coat-bond`（金属粘结层，0.0015）、`coat-tgo`（热生长氧化层，0.0008）、`coat-ysz`（陶瓷热障层，0.006）。层厚按真实比例夸张，陶瓷最厚、氧化层最薄。

## 四、运行时接口

```ts
const hero = engine.hero;
hero.show();                       // 精细叶片默认隐藏
hero.setCutaway(0.5);              // 0 完整，1 压力面壁移开露出通道
hero.setCoatings(1);               // 0 四层贴合，1 完全分开
const pose = hero.poseFor('turbine.stage-1-blades.001');  // 放到环上第 001 枚的位置
```

`poseFor` 返回 `{ position, quaternion, scale, matrix }` 并把精细叶片摆到该叶片的位置和朝向上（叶身高度一致，缩放 1）。互换动画不在本次范围。

已有的按 id 接口对精细叶片的每个对象都有效，例如：

```ts
// 开头：叶片落到第 001 枚的位置，环上那一枚同时隐藏
engine.hero.show();
engine.hero.setCutaway(0);
const pose = engine.hero.poseFor('turbine.stage-1-blades.001');
engine.setVisible('turbine.stage-1-blades.001', false);

// 问题一：剖开，再让孔一排排亮起
engine.hero.setCutaway(1);
for (const row of ['film-le-1', 'film-le-2', 'film-le-3', 'film-le-4',
  'film-ps-1', 'film-ps-2', 'film-ss-1', 'slot-te']) {
  engine.setColor(`turbine.hero-blade.${row}`, '#39d0ff');
}

// 问题三：涂层分开，陶瓷层变红
engine.hero.setCoatings(1);
engine.setColor('turbine.hero-blade.coat-ysz', '#e03b2f');
```

调试状态：`?debug=hero&angle=face|leading|oblique&cut=0..1&coat=0..1&rows=all|le&ceramic=1`，以及 `&pose=001&zoom=…`。

## 五、组装顺序调整

## 七、需要人确认的问题（本次没做到位的地方）

1. **前缘孔口在斜视时像刺**：前缘曲率大，孔的缘环和短管在掠射角下突出于表面，`hero-dark-leading.png`、`hero-white-leading.png` 能看到一排细刺。需要决定是缩小前缘孔半径，还是在前缘改用更贴合的开口。
2. **叶尖围边在近看有锯齿**：围边用比例轮廓直接拉伸，边缘在斜视时有细齿（`hero-zoom.png`）。
3. **通道和斜肋从孔里透出来**：孔开得较密，正面看时内部通道的亮面从孔口露出，显得像表面凸起。需要确认孔数与通道位置的配合。
4. **涂层样片是悬在叶片旁边的一块曲板**，不是从叶身表面“取下来”的；分开时四层沿 +Z 平移，仍未做真正的法线方向展开。
5. **剖开是用移开压力面壁实现的整体平移**，不是沿弦向平面的切割，所以内腔只在压力面一侧露出；如果需要更接近真实剖切的观感，需要另做裁剪方案。
6. **“精细叶片放在第 001 枚位置”的两张截图不可用**：环上第 001 枚在机匣和轮毂之间，近景相机落到了内部，远景只看到涡轮外环；`hero-pose-001-far.png` / `hero-pose-001-near.png` 留着说明问题，但需要视觉设计阶段重新布光布景后再拍。
7. **外形**：弦高比 1.2 是按说明做的，因此叶片看起来比环上的叶片宽得多；镜头切换时两者形状差异明显，只能靠位置和朝向对齐。
