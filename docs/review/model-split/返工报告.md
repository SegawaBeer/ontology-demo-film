## 2. 贯穿全机的黑色薄壳

原来 `combustor.casing.001`（1,248 个三角形、2 个原始连通块、x −1.895..2.047）按三角面沿四个轴向平面切开，切口取在直径突变或锥面与柱面交界处：x = −1.45、−1.05、−0.28、0.28、1.15。切出的六段：

| 段 | 归属模块 | 组件 | 理由 |
| --- | --- | --- | --- |
| x ≤ −1.45 | exhaust | 尾锥 | 半径从 0.66 收到 0.19 后到 0，是尾喷管的中心锥 |
| −1.45..−1.05 | turbine | 涡轮内锥壳 | 半径 0.61→0.50 的锥面，包住五级涡轮的内侧 |
| −1.05..−0.28 | core-casing | 核心机内壁 | 半径降到 0.18–0.40 的直筒段，是核心机内壁 |
| −0.28..0.28 | combustor | 燃烧室内壳 | 半径回升到 0.39–0.62 的鼓包段，位于火焰筒内侧 |
| 0.28..1.15 | compressor | 压气机前喇叭口 | 半径 0.32–0.42 并向右扩口，接压气机进口 |
| ≥ 1.15 | fan | 风扇内整流罩 | 半径 0.37–0.61 再收到 0，是风扇轮毂内的整流罩 |

切口用逐三角面裁剪（Sutherland–Hodgman，沿 x 裁剪并插值法线），不是整块分配，因此切口平直、无缝隙。切开后 combustor 模块所有零件的轴向范围都在 −0.480..0.480，落在 ±0.6 内。

- 截图：`assemble-6.png`（第 6 步只剩涡轮、主轴、压气机、燃烧室，没有尾锥和风扇段）、`combustor-transparent.png`（只有燃烧室半透明）、`explode.png`（燃烧室不再拖着一根黑管）。

## 4. 局部透明的零件继续跟着转子转

## 需要人判断的地方

- 四个切口位置是按半径突变选的，x=−0.28 与 0.28 这一对切口把燃烧室内壳限制在 ±0.28；如果后续视觉上希望燃烧室的内壳更长或更短，改 `tools/convert_turbofan.py` 里的 `SHELL_CUTS` 即可。
- 叶片轴向投影 0.041，比要求的上限 0.040 多 1 毫米；再压缩会让弦长掉出 0.045–0.05 区间，所以保留。
- 第四级没有鼓筒几何，第二、四级的叶根下面没有单独的盘；如果视频镜头会贴着这两级看，需要再补几何。
- 轮盘是生成的简化件（轮缘、辐板、中心孔），没有做真实涡轮盘的榫槽和冷却孔。
