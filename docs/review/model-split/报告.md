## 二、“初步观察”逐条核实

1. **风扇 16 片 + 16 块叶尖黄件：对。** 叶片 metal-mid、432 面，叶尖 accent-yellow、96 面，各 16 个，角度一一对应。
2. **尾喷段里是 5 级涡轮：对。** 位置 x≈−1.35、−1.45、−1.55、−1.65、−1.75；每级内圈 100 块、外圈 75 块，都是 2 面的平板。外圈实测半径 0.457–0.556，比观察里的 0.46–0.64 略窄。
3. **“涡轮”段其实是鼓筒：对。** x −1.00..−0.12 是带方块和螺栓的光滑筒体，没有叶片。归入 core-casing，理由：它是包围转子的静止筒壳，表面只有安装块和螺栓，没有叶片或轮盘特征；真正的涡轮叶片环在它后面单独成级。
4. **压气机圈数：基本对，另有发现。** 128 块在 x≈1.05；50 块在 x≈0.58/0.70/0.86；7 个环在 1.00–1.11；8 根支板在 x≈0.70。此外还有三圈各 64 块、半径约 0.40 的叶片环（x≈0.47/0.57/0.85），观察里没提到，我把它们和第 1 级的 128 块一起当成各级叶环。
5. **螺栓两圈：一圈对，一圈多一个。** x≈0.13–0.21 的核心机螺栓正好 64 个；x≈−1.90 那圈数出 65 个（比 64 多一个，可能是支架被并进去了）。
6. **plastic-cone-black 是整流锥：对。** 前锥和锥尖都在 fan.spinner 里。

## 三、认不出的零件

没有进入“其他”的连通块，数量为 0。但有三处是**按位置推断、置信度不高**，已在文档里注明：

- 贯穿全机的黑色薄壳（plastic-cone-black，x −1.9..2.05）按重心落进 combustor.casing，因此清单里没有单独的“尾锥”组件。
- core-casing.tiles 的 184 块是鼓筒表面小方块，功能未知，只按位置归属。
- 涡轮外环带（3 块）介于各级之间，按半径归入涡轮。

## 四、第一级叶片

`tools/blade.py` 生成：5 个截面、每截面 18 点，带弯度、厚度从 30% 收薄到 16%、扭转 42°→18°，下面是 0.026×0.015 的方形缘板和叶根。局部原点在叶根中心，+Y 沿半径向外，单片 130 顶点、252 个三角形。

尺寸落在原平板占位：r 0.304–0.450、x≈−1.355，不与轮盘和机匣相交。生成是确定性的，同一份代码每次得到相同的 100 枚。

单独看是一枚细长的扭转叶片，带缘板，能辨认；因为原始平板本身只有 15 毫米厚、146 毫米长，叶片只能做得很细长，比真实涡轮叶片瘦。

## 五、接口用法

```ts
const blades = engine.listParts('turbine.stage-1-blades').slice(0, 16);
engine.setColor(blades, '#e03b2f');
engine.setTransform(blades, { position: [0.9, 0.75, 0.55] });

const second = engine.cloneEngine();
second.root.scale.setScalar(0.5);
second.root.position.set(2, -1, 1.2);
scene.add(second.root);
second.setColor(second.listParts('turbine.stage-1-blades').slice(0, 30), '#e03b2f');
```

所有方法都接受零件、组件、模块 id 或它们的数组：`setColor`、`setDim`、`setOpacity`、`setVisible`、`setTransform`、`reset`、`getPart`、`listParts`、`pick`、`cloneEngine`。被平移或单独设透明度的零件会自动提升为独立网格，因此不会再跟着转子转。

## 六、实测

- 生成文件：`turbofan.glb` 3.1 MB（上限 15 MB），`turbofan-parts.json` 0.83 MB。
- 加载：本地开发服务器下 GLB 请求 14 ms、清单 3 ms；从打开页面到模型就绪 1.9 s（含 Vite 开发模式模块加载，生产构建更快）。生产构建 3 个资源、约 620 kB JS。
- 绘制：单台 171 次绘制调用、260,780 个三角形；两台 346 次、523,910 个三角形。
- 帧率：预览标签页当时处于后台，浏览器把动画帧压到 1–2 fps，读数不可用；改用强制同步渲染计时：两台发动机、3840×2160（“精细”档 2 倍超采样）下单帧 2.7 ms，折算约 370 fps，60 fps 达标。

## 七、偏差与未决

- 截图里第一级叶环在机匣内部。为了让红色可见，红 16 枚和抽出的两张图隐藏了其他模块；整机变暗那张保持整机可见，因此叶环本身被遮住一部分。
- 两台发动机那张，第二台缩小到 0.5 倍，30 枚红叶片在内部，截图里看不清；独立性由颜色和透明度状态可见，红色效果以第 5 张为准。
- 尾圈螺栓 65 个与观察的 64 差 1。
- 没有“其他”组件；上述三处低置信归属已写进 `docs/SOURCES.md`。
